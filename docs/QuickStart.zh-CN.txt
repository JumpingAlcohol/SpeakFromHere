AI Chat Reader — Windows 便携版

English: QuickStart.en.txt | 简体中文: QuickStart.zh-CN.txt

请先解压 ZIP 再运行。启动前，先退出已经在 VS Code 或其他终端中运行的朗读器，避免快捷键冲突。
双击 AIChatReader.exe 即可启动。程序包含 Python 和依赖，无需另外安装。
保持状态窗口打开或最小化。目前程序的状态提示使用英文。

Alt + S：朗读选中文字。按下后松开两个按键。
Alt + P：暂停；再按一次从暂停处继续。
Alt + X：停止朗读，程序保持运行。
Alt + Shift + Q：退出程序。
Ctrl + C：在程序的状态窗口中退出。

首次检查：在聊天中选一段文字，按 Alt + S，确认状态窗口的 Reading 预览正确。
朗读过程中依次测试暂停、继续、停止，再换一段文字开始朗读。
暂停时朗读新选择，会立即开始新的内容。停止会清除本次朗读位置。

预览只显示前 100 个字符，朗读使用完整文本。
模拟复制会替换剪贴板内容。目标应用必须支持用 Ctrl + C 复制选择。
语音使用本地安装的 Windows 声音，无需 API 密钥或在线语音服务。
当前版本只读选中文字，尚不支持自动识别整条回复或鼠标所在段落。
适用于 Windows 10/11、x64 系统。一次只运行一个朗读器实例。
