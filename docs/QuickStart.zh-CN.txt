SpeakFromHere v0.3.0 — 悬浮播放器候选版（所测朗读流程用户验收通过）
English: QuickStart.en.txt | 简体中文: QuickStart.zh-CN.txt

Read AI responses aloud from exactly where you want.
AI 回复，从你想听的位置开始。
理解回复边界：从支持的段落开头读到同一条已完成回复末尾，非任意字／句跳播。
原名 AI Chat Reader，保留原模块／设置路径。这是本地候选版，非新发布下载。

启动
退出其他朗读器，解压 ZIP，双击 SpeakFromHere.exe。
必须完整解压，保留主程序旁的 reader-worker/，不要只移动 exe。
Alt+E 需要辅助程序及其中的 _internal 运行文件。
无需终端、另装 Python 或 API 密钥。一次只运行一个实例。
置顶播放器位于右下角、任务栏上方；拖动标题可移动。

朗读和控制
Alt + S：朗读可复制的选中文字；按下后松开两个键。
Alt + E：指向已完成回复中支持的正文，从该段读到同一回复末尾；读取时鼠标不动。
Alt + P：暂停／继续（默认）。
Alt + X：停止（默认）。
Alt + Shift + Q：退出（默认）。
播放／暂停：暂停、继续；空闲时从头重播上次提交文字，首次朗读前禁用。
停止清除位置，不清除重播文字。点击播放器不会抓取新选文或猜测段落。
普通按钮不抢焦点；设置窗口为了输入接受焦点。
−／+：SAPI 语速 -10..10，默认 0，显示慢／标准／快，不是精确倍速。
语速改动立即提交，不重新开始朗读。用户报告当前声源在播放中逐渐变速；
响应可能延迟，取决于声源／缓冲，尚未独立测量。
中文／EN：切换并保存 GUI 语言；详细诊断仍为英文。
详细信息：错误／警告时展开可选中的完整英文提示，不自动复制／保存／上传。
身份错误包含失败的 Windows API 及错误码。
跳过提示：显示省略类型／数量，包括起读段落前的块。
详细信息列出回复块序号及“起点前／剩余回复中”的位置，不包含被跳过文字或文件名，
只在内存中保留。这不是原文高亮或同步进度；新读取替换，暂停／重播保留。
⚙：修改暂停／停止／退出键，重启生效；Alt+S／Alt+E 固定。
—：隐藏到托盘，点击通知区域图标恢复。
×：退出并释放快捷键。本候选版没有开机启动选项。

设置与隐私
%LOCALAPPDATA%\AIChatReader\settings.json（schema 2）只保存语速、控制键和
GUI 语言，不保存聊天／凭据。重播文字只在内存中，退出后清空。
预览最多 100 字符（面板可能显示更少），朗读使用完整文本。
选文复制会替换剪贴板，目标须支持 Ctrl+C；管理员权限应用可能受 Windows 限制。
控制键：Alt+字母 或 Alt+Shift+字母（A-Z），拒绝重复／保留键。
外部快捷键冲突会在启动时指出，并释放已取得的键。
旧 schema 1 直接读取不修改，主动保存才升级 schema 2。
降级前备份：v0.2.1 不认识 schema 2，会警告并使用默认值。
没有文件时使用默认值；无效文件保留并警告／使用默认值，拒绝直接更新。
备份后可明确确认“重置设置”替换原配置。

高级终端入口（可选，不要与 GUI 同时运行）
  .\SpeakFromHereConsole.exe --show-settings
  .\SpeakFromHereConsole.exe --set-rate 2 --set-hotkey 'pause=Alt+J'
  .\SpeakFromHereConsole.exe
终端设置重启生效；Ctrl+C 仅用于终端模式退出。
--settings-file PATH 选择隔离配置，不扩大应用支持。
--reset-settings 明确覆盖偏好、恢复默认值。

边界和检查
使用本地 Windows SAPI，本轮不增加自然声源／新语音后端。
Alt+E 仅接受 Windows 验证的 OpenAI.Codex_2p2nqsd0c76g0 包家族及其已注册的
app/ChatGPT.exe。数字版本更新本身不再触发拒读，仍须验证已检查的回复结构。
其他应用、无包身份的仿冒程序和改变／不安全的布局仍拒读，不保证未来永久兼容。
旧版已发布朗读器仍保留精确版本限制。
支持普通文字、标题、链接和已识别列表；跳过代码及已确认的非文本叶节点分隔线。
分隔线不能作为起读段落。若旧回复自身完成页脚及同一结构内后续 AI 回复标记可确认，
新回复正在生成不再挡住这条旧回复；当前正在生成的回复仍拒读。
已确认的“复制”页尾可带纯 24 小时时间或星期时间，例如“星期四23:43”／
“Thursday 23:43”。这些文本叶节点是元数据，不朗读、不能作为起点。
完整英文星期名称只有合成测试覆盖；缩写、AM/PM 及其他未检查日期格式仍可能拒读。
已识别的表格／表格组件、已知写作块容器、已检查的折叠文件摘要／行和简单“复制”页尾后活动
状态容器会省略；代码块省略也提示。测试过的编辑块／文件跳过已由用户确认。
已检查的表格组件包含正确类型的 grid 和限定工具栏；用户确认更新 Codex 后普通段落／表格测试通过，不代表所有布局兼容。
已知“重新生成回复／更多操作”叶节点仅在“复制”已确认后忽略；未知控件或隐藏子节点
仍拒读。英文对应标签仅有合成测试覆盖。
展开／改变的文件区域仍可能拒读。鼠标指向省略块不会猜测下一段，请人工用 Alt+S。
未知／受保护／边界含糊结构及其他应用仍拒读，不无条件跳过；Alt+E 失败不会自动复制。
读取不点击／复制／保存／上传；控制取消待完成读取。
两入口使用同一轻量 reader-worker，启动／收集不占用控制线程。
20 秒期限包含启动；取消的迟到进程仍会回收，不触发朗读。
关闭可能短暂等待系统启动返回以完成清理。
未修复报告：Alt+S／暂停延迟、开头吞字。跳过提示属于后续解析修改，不是原文高亮。

手动检查：连续三段新选文，暂停／继续、停止／重播；改语速后读新文字；
切语言并重启，托盘隐藏／恢复，退出／重启，Alt+E 首／中／末段。
留意开头字和延迟；静音自动测试不能代替真实聊天／听感验收。
测试省略块前后正文，查看跳过提示／详细信息，确认不读到下一条回复。
开发环境 Windows 11 x64，面向 Windows 10/11 x64；更广泛的电脑、应用／版本和
语言兼容性尚未确认。包内不含私人聊天。
