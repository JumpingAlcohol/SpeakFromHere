# SpeakFromHere 版本计划

[English](ROADMAP.md) | [简体中文](ROADMAP.zh-CN.md)

## 产品目标

一个轻量的 Windows AI 回复朗读工具。核心操作最终应当是：把鼠标放在某个段落，按快捷键，从这一段读到这条 AI 回复末尾。同时保留选文朗读、暂停／继续、停止和阅读设置。

优先支持用户当前的 Codex／ChatGPT 桌面使用场景。只有验证了其他应用的正文访问和回复边界后，才扩展支持范围；不承诺对所有 Windows 应用通用。

## 版本顺序

| 版本 | 范围 | 验收标准 |
| --- | --- | --- |
| **v0.1.0 — MVP 预览版** | 选文朗读、暂停／继续、停止／退出、Windows 便携程序、中英文文档。 | 连续换选文字能正确朗读；复制失败不读旧内容；两种退出方式可用；独立可执行文件能连续启动两次并释放快捷键；ZIP 包含两份说明。 |
| **v0.2.0 — 段落朗读预览版** | 识别鼠标所在段落及其所属 AI 回复，从该段读到这条回复末尾。保留 `Alt + S`；段落朗读计划使用 `Alt + E`。 | 在已验证的目标应用中，从首段、中间段、末段开始都正常；不会跨到下一条回复、用户消息、输入框或操作按钮。无法识别的位置有清晰提示，选文朗读仍能使用。 |
| **v0.2.1 — 阅读设置** | 保存本地 SAPI 语速，自定义暂停／停止／退出键；固定 Alt+S／Alt+E 双路径；明确冲突与人工兜底提示。 | 重启后设置保留，退出释放旧绑定，无效配置保留并警告／使用默认值，冲突改动拒绝保存。 |
| **v0.3.0 — 桌面界面** | 右下角悬浮播放器、托盘、播放状态、重播、语速控制、保存中英文界面及控制键设置。开机启动留待单独的主动开启功能。 | 双击无终端；普通控制保留目标焦点，隐藏／恢复正常，退出释放资源，偏好持久保存。仍需真实聊天／听感检查。 |
| **v0.4.0 — 声音选项** | 选择声音、可替换朗读后端，以及可选的更自然声源；保留本地 Windows 语音。 | 切换声音不破坏控制；支持的后端均能暂停、停止和取消。在线语音须主动启用，明确联网、费用和文本处理要求；出错可返回本地语音。 |
| **v0.9.0 — 公开测试版** | 兼容性检查、长回复可靠性、干净环境安装包，以及根据反馈修复问题。 | 明确已验证的 Windows／应用组合；长回复、连续使用、中断和升级通过发布检查；无需安装 Python 即可使用；不支持的环境有清晰提示。 |
| **v1.0.0 — 稳定版** | 在明确支持的环境中，提供可靠且文档完整的核心使用流程。 | 段落朗读、选文兜底、播放控制、设置和桌面界面均验证通过；支持范围内没有已知阻断问题；保留上一版可用下载。 |

以上顺序代表优先级，不是保证完成日期。如果某版尚未满足验收标准，可以拆分；没有完成的内容不能写成已经发布的功能。

## v0.2.0 验收节点

源码和便携程序于 2026-10-01 通过验收：用户先在实际目标应用中确认段落起读、停在同一条回复末尾、切换起点／回复及播放控制，随后确认打包程序也正常。便携预览包还通过了启动／控制／退出及打包读取进程检查。目前仅接受桌面应用包 `OpenAI.Codex_26.928.3736.0_x64__2p2nqsd0c76g0`；可编辑写作块、表格、用户消息、其他应用和未知布局不在段落朗读范围内。保留 v0.1.0 作为选文朗读旧版兜底。

v0.2.1 设置验收仍未完成。2026-10-01 用户明确要求先做 GUI，再处理延迟／开头吞字及不兼容块问题。v0.3.0 预览版新增 GUI／托盘／语言选择及有边界跳过与省略提示。更新 Codex 后所测普通段落／表格／编辑块／文件流程已获用户确认；ISSUE-001 听感反馈仍开放。验证范围见 v0.3.0 发布说明。开机启动、声源后端和音量暂缓。原生创建进程可能短暂延迟段落起读，收集测试不证明启动完全即时。

此预览版已检查的验收范围：

1. 确认 Windows 无障碍接口能否提供目标应用的回复正文、段落顺序和可靠的所属回复信息。
2. 验证鼠标位置到段落的定位，包括重复段落、链接／列表、换行，以及同一条回复中屏幕外的部分。
3. 编写并测试有边界的提取规则：当前段落一直到同一条 AI 回复末尾。
4. 接入现有播放控制，再在真实应用中验证，并注明实际测试的应用与版本。

预览版跳过代码块，将列表项作为起点；选文朗读仍读用户选择。这些不是 v0.1.0 的功能。下一步诊断 ISSUE-001，并仅针对复现的其他布局继续验证 ISSUE-002；不能悄悄扩大已检查应用／版本范围。发布说明：[v0.3.0](releases/v0.3.0.md)。

如果应用没有提供足够结构，记录限制并保持 v0.1.0 可用。可以考虑一个本地阅读面板，由用户明确复制一条完整回复进去，再从某段开始读；但这属于另一种操作流程，不能说成直接从 Codex／ChatGPT 原界面定位段落。不能未经说明把产品改成浏览器插件，也不能在缺乏实际证据时宣称支持桌面段落朗读。

## 开发与发布规则

- 一次推进一个里程碑，达到验收标准后再做可选增强。
- 中英文 README、路线图和下载包说明同步维护；语言约定记录在 `AGENTS.md`。
- 运行相关自动检查，并在实际支持的应用中完成手动端到端检查。公开测试用合成文本，不发布捕获到的私人聊天内容。
- 新增了经过验证的用户功能，或提供了有用的测试后下载包时，再发布版本。完成里程碑才发版，不为每个小提交单独发布。
- 二进制文件放在 Release 附件中，不进入 Git 源码历史。确认发布包、校验值和标签对应源码一致。

## 核心版本之后再考虑

上一句／下一句、跨会话记住朗读位置、同步高亮、悬浮朗读按钮和更多应用适配，留待核心流程可靠后评估。声音克隆、完整屏幕阅读器替代品、自动在后台读取全部聊天，不在当前计划中。

2026-10-02 明确：v0.3.0 新增已识别块的跳过及明确提示（ISSUE-002／007），提示不是高亮。后续视觉功能应区分计划朗读段落、被省略区域和当前实际发声位置，不能把已计划／已提交文字当作已经听过。评估不修改 Codex 内容的段落覆盖层，并处理滚动／移动／缩放、取消和隐私。本预览版未实现或承诺原文着色／同步进度。
