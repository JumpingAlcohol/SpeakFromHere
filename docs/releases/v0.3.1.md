# SpeakFromHere v0.3.1 — Audio Stability Preview

Read AI responses aloud from exactly where you want.

## English

A focused audio-stability update to the v0.3.0 Windows preview. Paragraph reading still starts at a supported paragraph's **beginning** and stops at the end of the **same completed assistant reply**. This is not a stable or universally compatible release.

### Changes

- GUI and console share position-preserving pause/resume for the waveform output owned by their SAPI voice. This improves the reproduced delayed-pause path, rather than merely returning quickly from the pause API.
- Stopping or replacing paused speech clears only that voice's queued buffers before SAPI cancellation, avoiding paused-writer hangs and brief replay of old buffered speech. Rate changes, replay and exit retain their existing behavior.
- A user-approved temporary startup workaround adds a soft, faded **400 ms audible cue before the first nonempty read per launch**, through the same voice/output. Opening the app is silent. Resume, replay and subsequent reads do not repeat the cue; empty/failed captures do not consume it.
- The cue obeys this voice's volume. Text remains plain text, not XML. A text-submission error cancels queued audio without replacing successful replay text. No system-volume/default-device or settings-schema change.
- No new voices, online speech, highlighting, applications or paragraph-reading scope are added. Alt+S/Alt+E and settings paths are unchanged.

### Download and start

1. Download **SpeakFromHere-Windows-x64.zip** below; Python and dependencies are included, no API key needed.
2. Exit the old reader and extract the **entire ZIP** to a new folder. Keep **reader-worker/** beside both executables; do not move only the exe.
3. Double-click **SpeakFromHere.exe**. Use **Alt+S** for selected copyable text or **Alt+E** over supported ordinary text in the inspected Codex desktop app.
4. Defaults: **Alt+P** pause/resume, **Alt+X** stop, **Alt+Shift+Q** exit. Both quick starts are included; only run one instance. **SpeakFromHereConsole.exe** remains the optional advanced entry.

**SHA256SUMS.txt** verifies the ZIP. English and Simplified-Chinese quick starts are also separate assets. Historical v0.1.0/v0.2.0/v0.3.0 releases remain available; do not run the old and new readers together. Settings remain schema 2; back up before downgrading to a version that does not understand that schema.

### Verification and boundaries

- **199 tests pass**, no skips with Windows/GUI/UIA/portable opt-ins. Actual embedded GUI/console checks pass **99 each**, helper checks **66**. Complete ZIP/helper/canonical guides and two successive portable startup/control/exit runs are verified.
- Tests include real muted device-position checks during speech/cue pause, stop, replacement and rate changes, plus file-only cue duration/fade/volume/plain-text/no-repeat checks. Regressions first failed on missing cue, uncancelled cue after a text error and raw-stream volume bypass, then passed after fixes. No audio recording or private-chat fixtures are included.
- The user confirms the tested new-bundle workflow works. Silent checks do not establish audible timing or broad device compatibility.
- The cue is a **workaround**, not a universal cure for opening loss or hypothetical clipping after long idle. Non-waveform/unopened outputs keep the ordinary SAPI pause path; there is no zero-delay/all-device promise.
- Existing verified skipping/omission notices remain. Unknown/protected/ambiguous layouts, incomplete captures and the currently generating reply still reject; Alt+E never auto-copies on failure. English footer/date labels remain synthetic-tested rather than live-English accepted. The separate compaction-status post-fix capture remains pending.
- Intended for Windows 10/11 x64; verified on the development Windows 11 x64 machine. More natural/replaceable voices and original-text highlighting are planned, not implemented.

## 简体中文

**AI 回复，从你想听的位置开始。**

这是针对 v0.3.0 Windows 预览版的音频稳定性更新。段落朗读仍从支持的**段落开头**读到**同一条已完成 AI 回复末尾**，不是稳定或通用兼容版本。

### 本次改动

- GUI／终端共用保留位置的本声源波形暂停／继续，改进已复现的暂停延迟，而不只看暂停 API 是否立即返回。
- 停止／替换暂停中的语音时，先清除该声源排队缓冲，再交给 SAPI 取消，避免暂停写入卡住及短暂重播旧音频。保留语速、重播和退出行为。
- 经用户同意，暂时在**每次启动后首次非空朗读前**，通过同一声源／输出加一次柔和、淡入淡出的 **400 毫秒有声提示音**。仅打开程序不发声；继续、重播和后续朗读不重复，空选文／读取失败不消耗提示音。
- 提示音遵循本声源音量；正文仍按纯文本而非 XML 处理。语音提交失败取消排队音频，不把失败文本当作成功的重播内容。不改系统音量／默认设备或设置 schema。
- 不新增声源、在线语音、高亮、应用或段落支持范围。Alt+S／Alt+E 和设置路径不变。

### 下载与启动

1. 下载下方 **SpeakFromHere-Windows-x64.zip**，已包含 Python 与依赖，无需 API 密钥。
2. 退出旧朗读器，**完整解压**到新文件夹。保留主程序旁的 **reader-worker/**，不要只移动 exe。
3. 双击 **SpeakFromHere.exe**；选文用 **Alt+S**，在已检查 Codex 桌面应用的支持正文上指鼠标按 **Alt+E**。
4. 默认 **Alt+P** 暂停／继续、**Alt+X** 停止、**Alt+Shift+Q** 退出。两份说明已包含在包内，一次只运行一个实例。**SpeakFromHereConsole.exe** 仍是可选高级终端入口。

**SHA256SUMS.txt** 校验 ZIP，两份中英文说明也作为独立附件。保留历史 v0.1.0／v0.2.0／v0.3.0 下载，旧版与新版不要同时运行。设置仍为 schema 2，降级到不认识此 schema 的版本前请备份。

### 验证与边界
