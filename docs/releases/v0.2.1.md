## English

- Local settings: `%LOCALAPPDATA%\AIChatReader\settings.json`, schema version 1, atomic saves. Only rate/control bindings; no chats or credentials.
- `--show-settings`, `--set-rate N` (-10 to 10, default 0), `--set-hotkey action=chord`, `--reset-settings`; commands exit without speech or hotkey registration. Restart to apply changes.
- Only pause/stop/exit can change, with Alt+LETTER or Alt+Shift+LETTER. Alt+S/Alt+E remain fixed. Duplicate/reserved/unsupported bindings cannot be saved. External conflicts name the actual key and roll back acquired bindings.
- Invalid settings are preserved with a warning and default startup. Invalid files cannot be updated without explicit reset. `--settings-file PATH` supports isolated testing.
- Paragraph rejection reminds users to select text and press Alt+S; no automatic clipboard fallback. Inspected app/build and unsupported tables/editors/user-message boundaries are unchanged. Code blocks remain skipped.
- Windows process creation occasionally delays initial capture by about two seconds; no instantaneous startup guarantee. Tests isolate background result collection from this OS startup delay.
- Portable ZIP includes executable and English/Chinese quick starts; previous downloads are untouched. GUI/tray/language switching and natural voices remain future milestones.

Before publication: manually confirm rate, custom pause/resume, persisted restart, Alt+S/Alt+E regression, unsupported-content fallback, stop/exit in source and portable mode. Automated evidence is recorded in CONTEXT.md; it does not replace manual audio acceptance.
