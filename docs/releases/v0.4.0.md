# SpeakFromHere v0.4.0 — Local Voice Selection Preview

Read AI responses aloud from exactly where you want.

## English

This Windows preview adds selection of installed local SAPI voices. It does not add downloadable AI models, online speech or natural-voice guarantees. Alternative backends are deferred; reading-position visualization is the next separate milestone, not part of this download.

### Changes

- Settings lists voices exposed by Windows SAPI, including available language metadata. Choose Windows default or an installed voice; the stable token ID is saved, not its name or list position.
- Stop playback before switching. Save applies the voice to this reader; Save voice & preview saves only the voice choice and reads a fixed bilingual sample without capturing text or replacing the last reply retained for replay.
- Playing/paused speech refuses voice changes. Missing/failed saved voices show a warning and use the local default without rewriting the saved preference. A failed settings write restores the previous runtime voice/rate.
- Silent console commands: `--list-voices`, `--set-voice ID`, `--set-voice default`, and `--show-settings`. Settings commands do not register hotkeys. Restart a running reader after console changes.
- Alt+S selected-text reading, Alt+E bounded paragraph reading, playback controls, the floating GUI/tray, omission notices and the temporary first-read cue retain their existing scope.

### Download and upgrade

1. Exit the old reader. Back up `%LOCALAPPDATA%\AIChatReader\settings.json` if present.
2. Download **SpeakFromHere-Windows-x64.zip**, extract the entire archive to a new folder and retain **reader-worker/** beside both executables.
3. Double-click **SpeakFromHere.exe**. No Python installation or API key is needed. Run only one instance.
4. Open Settings, stop speech, choose a local voice and save. Defaults remain Alt+S read selection, Alt+E paragraph, Alt+P pause/resume, Alt+X stop, Alt+Shift+Q exit.

Settings save as **schema 3**. Schema 1/2 load without rewriting and use the default voice until you explicitly save. **v0.3.1 and earlier do not understand schema 3** and warn/use defaults on downgrade; restore a compatible backup if needed, do not reset the only backup. The legacy module/distribution/settings paths are retained. Historical releases remain unchanged.

The ZIP contains both executables, the complete helper runtime and both canonical quick starts. **SHA256SUMS.txt** checks the ZIP; the two quick starts are also separate release assets.

### Verification and limits

- Final release checks pass 225 opt-in Windows/GUI/UIA/portable tests with no skips; actual embedded GUI/console checks pass 125 each, helper 66. ZIP/helper/canonical guides and two successive portable startup/control/exit/hotkey-release runs pass; pip/compileall/diff checks pass.
- Native tests exercise both installed test-machine voices, Huihui and Zira, through file-only synthesis and muted playback controls. The user confirms tested English listening, restart retention and normal candidate workflow. This is not an all-machine/all-voice acceptance claim.
- A language-specific voice can omit unsupported-language text. The fixed bilingual preview may not be spoken in full. There is no automatic language switching, voice installation, OneCore registry workaround or cloud speech.
- Paragraph reading starts at a supported paragraph's beginning and stops at the same completed reply's end in the inspected Codex desktop app. Other apps, unknown/protected/ambiguous layouts and current generation remain unsupported; Alt+E never silently copies on failure.
- Recognized table/editor/code/file/status regions are omitted with disclosure, not narrated. There is no synchronized highlighting or reading history.
- The 400 ms first-read cue remains a temporary workaround, not a universal audio-loss/long-idle solution. No zero-delay or universal compatibility promise.

## 简体中文

本 Windows 预览版新增已安装的本机 SAPI 声源选择，不增加可下载 AI 模型、在线语音或自然人声保证。其他语音后端暂缓；阅读位置可视化是下一独立阶段，不包含在本次下载中。

### 新增内容

- 设置列出 Windows SAPI 提供的声源及可用语言信息。可选 Windows 默认或已安装声源；保存稳定 token ID，不按名字或列表位置保存。
- 切换前停止朗读。保存后当前程序使用新声源；保存声源并试听只保存声源选择，再朗读固定双语样句，不抓取文字、不覆盖上次回复的重播内容。
- 播放／暂停时拒绝切换；已保存声源缺失或加载失败时提示并使用本机默认，不改写偏好。设置写入失败会恢复先前运行时声源／语速。
- 终端可静默使用 `--list-voices`、`--set-voice ID`、`--set-voice default`、`--show-settings`，不注册快捷键。终端修改后重启正在运行的朗读器。
- Alt+S 选文、Alt+E 有边界段落读取、播放控制、悬浮窗／托盘、省略提示与暂时首读提示音保持原有范围。

### 下载和升级

1. 退出旧程序；如有 `%LOCALAPPDATA%\AIChatReader\settings.json`，先备份。
2. 下载 **SpeakFromHere-Windows-x64.zip**，完整解压到新目录，保留两个主程序旁的 **reader-worker/**。
3. 双击 **SpeakFromHere.exe**，无需另装 Python 或 API 密钥，一次只开一个实例。
4. 打开设置，停止朗读，选本机声源并保存。默认键保持 Alt+S 选文、Alt+E 段落、Alt+P 暂停／继续、Alt+X 停止、Alt+Shift+Q 退出。

保存设置使用 **schema 3**。schema 1／2 读取时不改写、使用默认声源，主动保存才升级。**v0.3.1 及更早版不认识 schema 3**，降级会提示并使用默认值；必要时恢复兼容备份，不要重置唯一的备份。原模块／分发名／设置路径不迁移，历史 Release 不改。

ZIP 包含两个程序、完整辅助运行文件与两份规范快速说明。**SHA256SUMS.txt** 校验 ZIP，两份说明也单独提供下载。

### 验证和限制

- 最终发布检查 225 项 Windows／GUI／UIA／便携测试无跳过通过；包内 GUI／终端各 125 项、辅助程序 66 项通过。完整 ZIP／辅助运行文件／规范说明、两次便携启动／控制／退出／快捷键释放及 pip／编译／差异检查通过。
- 原生测试覆盖本机 Huihui／Zira 的文件合成及静音播放控制；用户确认所测英文听感、重启记忆及候选流程正常，不代表所有电脑／声源均验收。
- 单语声源可能省略其他语言，固定双语试听可能读不全；不自动换语言、不安装声音、不改 OneCore 注册表、不接云端语音。
- 段落读取仍仅针对已检查 Codex 桌面应用，从支持段落开头到同一已完成回复末尾。其他应用、未知／受保护／模糊布局及当前生成回复仍不支持；Alt+E 失败不自动复制。
- 已识别表格／编辑器／代码／文件／状态区域明确提示后省略，不朗读这些块；没有同步高亮或阅读历史。
- 400 毫秒首读提示音仍为暂时方案，不全面解决音频丢失或长时间闲置起读，不承诺零延迟／通用兼容。
