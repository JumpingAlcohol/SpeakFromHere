# AI Chat Reader v0.1.0 — MVP Preview / MVP 预览版

## English

The first downloadable Windows x64 preview. Extract `AIChatReader-Windows-x64.zip` and double-click `AIChatReader.exe`; Python is included. Close an existing reader instance before starting.

- `Alt + S`: read selected text.
- `Alt + P`: pause/resume.
- `Alt + X`: stop speech without exiting.
- `Alt + Shift + Q`, or `Ctrl + C` in the status window: exit.
- English and Simplified Chinese quick-start guides are included.

Speech uses a locally installed Windows voice. Clipboard copying replaces the clipboard; the status preview is limited to 100 characters, but speech receives the full selected text.

**Not implemented:** paragraph-under-mouse reading, automatic reply boundaries, a dedicated GUI, UI language switching or natural online voices. This preview has been checked on the development Windows 11 x64 machine; broader compatibility testing remains planned.

Validation: 22 automated checks including Windows speech integration, two successive standalone executable runs, and user-confirmed selected-text reading/playback controls in the source version. The packaged app still needs user feedback across other machines.

## 简体中文

首个可下载的 Windows x64 预览版。解压 `AIChatReader-Windows-x64.zip`，双击 `AIChatReader.exe` 即可使用；程序包含 Python。启动前请退出已运行的朗读器。

- `Alt + S`：朗读选中文字。
- `Alt + P`：暂停／继续。
- `Alt + X`：停止朗读，不退出程序。
- `Alt + Shift + Q`，或在状态窗口中按 `Ctrl + C`：退出。
- 下载包附带英文、简体中文两份使用说明。

语音使用本地安装的 Windows 声音。复制会替换剪贴板；状态预览只显示前 100 个字符，但朗读会使用完整选文。

**尚未实现：**鼠标所在段落朗读、自动识别回复边界、独立图形界面、界面语言切换和更自然的在线语音。此预览版已在开发用 Windows 11 x64 电脑上检查；更广泛的兼容性测试仍在计划中。

验证情况：22 项自动检查（包含 Windows 语音集成检查）、两次连续独立可执行文件运行，以及用户已确认的源码版选文朗读和播放控制。其他电脑上的打包版体验仍需要反馈。
