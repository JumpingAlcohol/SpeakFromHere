# AI Chat Reader v0.2.0 — Paragraph Reading Preview / 段落朗读预览版

## English

Point at ordinary text in a completed AI reply and press **Alt + E**: reading starts at that paragraph's beginning and stops at the end of the same reply. No selection is needed. The portable executable enables this shortcut by default; Python source uses `--paragraphs`.

Extract `AIChatReader-Windows-x64.zip` and double-click `AIChatReader.exe`. Python and the UI Automation dependencies are included. Close any older reader first. The ZIP includes English and Simplified Chinese quick-start guides; `SHA256SUMS.txt` verifies the archive.

- Supports ordinary reply paragraphs, headings, recognized list items and inline links; skips code blocks.
- Retains **Alt + S** selected-text reading, **Alt + P** pause/resume, **Alt + X** stop, and **Alt + Shift + Q** / terminal **Ctrl + C** exit.
- A new read replaces pending capture; pause, stop and exit cancel it. A hung app is limited by a 20-second worker timeout.
- Paragraph reading does not click, copy, save chats or upload text. Windows SAPI speech remains local. Selected-text copying still replaces the clipboard; the preview shows only 100 characters, while speech uses the full extracted text.

**Supported paragraph target:** the inspected Codex desktop package `OpenAI.Codex_26.928.3736.0_x64__2p2nqsd0c76g0` (`app/ChatGPT.exe`). Other apps, browsers or updated builds are rejected until inspected. Tables, editable writing blocks, user messages and unknown/incomplete reply layouts are not supported by Alt + E; use Alt + S instead. Chinese interface structure was inspected locally; English markers have synthetic test coverage only. This is not universal ChatGPT or Windows paragraph support.

Validation on 2026-10-01: all 88 automated tests including Windows speech/UIA and bundled-worker checks; two isolated executable startup/control/exit runs; user-confirmed paragraph reading and controls in source mode and then the portable executable on the development Windows 11 x64 machine. Broader compatibility is not yet established.

No dedicated GUI, persisted reading settings, UI language selector or natural online speech backend yet. This is a **pre-release preview**, not v1.0.0. The [v0.1.0 selected-text preview](https://github.com/JumpingAlcohol/ai-chat-reader/releases/tag/v0.1.0) remains available.

## 简体中文

把鼠标放在一条已完成 AI 回复的普通正文上，按 **Alt + E**，即可从该段开头读到同一条回复末尾，无需选择文字。便携程序默认启用；Python 源码使用 `--paragraphs` 参数。

解压 `AIChatReader-Windows-x64.zip`，双击 `AIChatReader.exe`，无需安装 Python 或 UI Automation 依赖。启动前退出旧朗读器。ZIP 包含中英文使用说明；`SHA256SUMS.txt` 用于核对压缩包校验值。

- 支持普通回复段落、标题、已识别的列表项和行内链接，跳过代码块。
- 保留 **Alt + S** 选文朗读、**Alt + P** 暂停／继续、**Alt + X** 停止，以及 **Alt + Shift + Q**／终端 **Ctrl + C** 退出。
- 新读取替换待完成的检查；暂停、停止和退出取消检查。目标应用无响应时，独立读取进程在 20 秒后超时。
- 段落读取不点击、不复制、不保存聊天、不上传文字；Windows SAPI 仍是本地语音。选文复制仍会替换剪贴板；预览仅显示 100 字符，朗读使用完整提取内容。

**已支持的段落目标：**检查过的 Codex 桌面应用包 `OpenAI.Codex_26.928.3736.0_x64__2p2nqsd0c76g0`（`app/ChatGPT.exe`）。其他应用、浏览器或更新后的版本会被拒绝，直到重新检查。表格、可编辑写作块、用户消息、未知或不完整的回复布局不支持 Alt + E，可改用 Alt + S。中文界面结构已本地检查；英文标记仅有合成测试覆盖。这不是通用 ChatGPT 或所有 Windows 应用的段落支持。

2026-10-01 验证：包含 Windows 语音／UIA 及打包读取进程检查的全部 88 项自动测试通过；独立程序连续两次通过启动／控制／退出检查；用户在开发用 Windows 11 x64 电脑上，先确认源码段落朗读和控制正常，再确认便携程序正常。更广泛的兼容性尚未验证。

目前没有独立图形界面、持久化阅读设置、界面语言切换或自然在线声源。这是 **预发布预览版**，不是 v1.0.0；[v0.1.0 选文预览版](https://github.com/JumpingAlcohol/ai-chat-reader/releases/tag/v0.1.0) 保留下载。
