# SpeakFromHere v0.3.0 — Floating Player & Bounded Skipping Preview

Read AI responses aloud from exactly where you want.

## English

A Windows preview release with a terminal-free floating player and reply-aware paragraph listening. This is not a stable or universally compatible release.

### What's new

- Compact, draggable, always-on-top player at the bottom right; play/pause/resume, stop, in-memory replay, tray hide/restore and exit. No saved reading history.
- Persisted English/Chinese interface, SAPI rate -10..10 and configurable pause/stop/exit shortcuts. Rate changes are submitted without restarting speech; audible response depends on the voice. Alt+S and Alt+E stay fixed.
- Read from a supported paragraph's **beginning** to the end of the **same completed assistant reply** in the inspected Windows Codex desktop application.
- Skip recognized code blocks, tables/table widgets, the inspected writing-block wrapper, collapsed edited-files areas and simple post-reply activity metadata. Continue with readable prose. An amber notice and Details disclose omitted types/counts and ordered block positions, including omissions before the starting paragraph, without omitted text or filenames.
- Verify Windows package identity and registered executable, then reply structure, instead of rejecting solely on a numeric version change. Other applications still require separate adapters; future layouts are not guaranteed.
- Correct the GUI/worker physical-coordinate mismatch that could cause false application-identity refusal. Both entries use the same lightweight capture helper; pending work is cancellable. Details exposes complete English diagnostics without automatic copying, saving or uploading.

### Download and start

1. Download **SpeakFromHere-Windows-x64.zip** below. Python and dependencies are included; no API key is needed.
2. Exit the old reader, then extract the **entire ZIP** into a new folder. Keep **reader-worker/** beside both executables; do not move only the exe.
3. Open **SpeakFromHere.exe** for the floating player. Select copyable text and press **Alt+S**, or point at a supported paragraph in the inspected Codex app and press **Alt+E**.
4. Default controls: **Alt+P** pause/resume, **Alt+X** stop, **Alt+Shift+Q** exit. Read **QuickStart.en.txt** or **QuickStart.zh-CN.txt** for settings and limitations. Only run one reader instance.

SHA256SUMS.txt verifies the ZIP. Both quick starts are also included inside the ZIP. SpeakFromHereConsole.exe is the optional advanced console entry.

Intended for Windows 10/11 x64; verified on the development machine's Windows 11 x64 desktop. The existing repository/module/settings paths are retained. Settings schema 2 preserves schema 1 until explicit saving; **back up settings before downgrading** because v0.2.1 cannot read schema 2. Historical v0.1.0/v0.2.0 downloads remain unchanged.

### Verification and known limitations

- All **190 tests passed** with Windows/GUI/UIA/portable opt-ins enabled. Embedded GUI/console checks passed **90 each**, helper checks **66**; portable startup/control/exit and complete ZIP/helper/guides were checked.
- The user confirmed tested ordinary-paragraph/table/editor/file workflows after updating Codex. The exact updated package version was not captured. This is scoped acceptance, not evidence for every future app/build/language.
- Startup/pause delays and missing opening characters remain open reports. Windows SAPI is still the backend; natural/replaceable voices and original-text highlighting are **not implemented**.
- Unknown/protected/ambiguous layouts, incomplete captures and the currently generating reply still reject. Hovering a skipped block does not guess a new start. Alt+E failures never auto-copy; use Alt+S manually.
- English footer/date markers have synthetic coverage, not live English acceptance. A separate post-fix compaction-status capture remains pending.
- Silent tests do not establish audible timing or broad machine compatibility. No private chat snapshots or credentials are bundled.
