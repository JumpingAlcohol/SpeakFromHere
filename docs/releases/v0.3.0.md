## English

- Default portable entry is a compact dark bottom-right, draggable, topmost player without a terminal. Main buttons do not activate it; settings accept typing.
- Play/pause/resume, stop and in-memory replay of last submitted text; no saved reading history. New capture still uses fixed Alt+S / Alt+E, not guessed mouse locations after clicking the player.
- SAPI rate -10..10 is submitted immediately without restarting speech or claiming exact multipliers. User reports gradual mid-playback changes with the current voice; audible timing is voice-dependent and not independently measured. English/Chinese labels and language persistence; pause/stop/exit dialog changes require restart.
- Hide to notification area and click icon to restore; × exits and releases keys. No login-startup option yet.
- GUI and console entries plus both canonical quick starts and a shared lightweight `reader-worker/` runtime. Extract the whole ZIP and keep this folder beside the main executables. Paragraph requests no longer unpack/load the full reader each time; startup/collection run off the control thread with cancellation and a startup-inclusive 20-second deadline. No parser safety checks were relaxed.
- **Details** expands the complete selectable error/warning in memory, without automatically copying/saving/uploading. Windows identity failures include API stage and numeric error code. GUI-only refusal remains unconfirmed; direct same-point workers succeeded, so a full GUI error is still needed.
- Settings schema 2; reads schema 1 unchanged until explicit save. Back up before downgrade: v0.2.1 cannot read schema 2. Invalid files are preserved; reset needs explicit confirmation.
- Existing latency, opening-audio loss and table/edited-files whole-reply rejection reports remain open. This user-approved GUI-first milestone is not a fix for them. No new voices/app support.

## 简体中文

未发布 v0.3.0 GitHub Release。用户确认更新 Codex 后所测朗读流程通过；原延迟／开头吞字反馈仍独立开放。

- 便携默认入口为右下角深色、可拖动、置顶小播放器，无需终端；普通按钮不抢焦点，设置接受输入。
- 播放／暂停／继续、停止、内存中重播上次文字，不保存朗读历史。新读取仍用固定 Alt+S／Alt+E，不会点击后猜测起点。
- SAPI 语速 -10..10 立即提交，不重新开始朗读、不标精确倍数。用户报告当前声源在播放中逐渐变速，听感时机取决于声源，尚未独立测量。中英文标签和语言持久保存；控制键设置需重启。
- 隐藏到通知区域、点击图标恢复；× 退出并释放键。暂无开机启动。
- GUI／终端入口附两份规范说明及共用轻量 `reader-worker/`，须完整解压并将其保留在主程序旁。段落请求不再重复解包／导入完整朗读器，启动／收集不占用控制线程；保留取消及包含启动的 20 秒期限，不放宽解析保护。
- **详细信息**可展开内存中可选的完整错误／警告，不自动复制／保存／上传。Windows 身份失败包含 API 阶段和数字错误码。仅 GUI 拒读仍未确认原因；同点直接读取均成功，仍需完整 GUI 错误。
- schema 2，旧 schema 1 在主动保存前保持原文件。降级前备份，v0.2.1 无法读取 schema 2；无效文件保留，重置须明确确认。
- 延迟、开头吞字、表格／已编辑文件导致整条拒读仍未解决。用户批准先做 GUI 不代表修复；未增加声源／应用支持。
- 后续解析修复：已确认的非文本叶节点分隔线不再挡住正文；若同一对话结构内有后续 AI 回复标记，且旧回复自身已确认完成，新回复生成不再挡住它。最新正在生成的回复、不安全分隔线及未知／编辑区／表格结构仍拒读。新采集的失败检查结果已通过离线回放，GUI／console 实际声音复测仍待完成。
